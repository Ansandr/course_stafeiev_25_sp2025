# Компілятор мови програмування (Варіант 25)

Проєкт курсової роботи з дисципліни "Системне програмування". Реалізація компілятора для мови програмування варіанту 25.

Репозиторій: <https://github.com/Ansandr/course_stafeiev_25_sp2025>

---

## 📋 Вимоги

- **Git** (для клонування репозиторію)
- **Visual Studio 2019** (Platform Toolset v142)
- **Boost** (header-only) — потрібно завантажити окремо
- **Graphviz 14.0.5** (опціонально, для візуалізації автоматів)

---

## 📥 Завантаження проекту

**Клонуйте репозиторій:**

```powershell
git clone https://github.com/Ansandr/course_stafeiev_25_sp2025.git
cd course_stafeiev_25_sp2025
```

## 📦 Встановлення залежностей

### Крок 1: Завантаження Boost C++ Libraries

**Призначення:** Бібліотека для роботи з регулярними виразами та парсингу (Boost.Spirit)

1. **Завантажте архів:**
   ```
   https://github.com/KozakNazar/cw_sp2__2024_2025/blob/main/boost.rar
   ```

2. **Розпакуйте архів** за допомогою WinRAR або 7-Zip

3. **Помістіть розпаковану папку** в кореневу директорію проекту:
   ```
   course_stafeiev_25_sp2025\boost\
   ```

4. **Перевірте структуру:**
   ```
   boost\
   ├── boost\
   │   ├── algorithm\
   │   ├── array.hpp
   │   ├── spirit\
   │   └── ...
   └── libs\
   ```

> **Важливо:** Папка повинна називатися **`boost`**, а всередині має бути вкладена папка **`boost`** з хедерами.

---

### Крок 2: Завантаження Graphviz (опціонально)

**Призначення:** Генерація діаграм скінченних автоматів у форматі `.dot` → `.svg`

1. **Завантажте архів:**
   ```
   https://gitlab.com/api/v4/projects/4207231/packages/generic/graphviz-releases/14.0.5/windows_10_cmake_Release_Graphviz-14.0.5-win32.zip
   ```

2. **Розпакуйте архів** за допомогою 7-Zip або WinRAR

3. **Помістіть розпаковану папку** в:
   ```
   dfa_generator__2025\Graphviz-14.0.5-win32\
   ```

4. **Перевірте структуру:**
   ```
   dfa_generator__2025\
   ├── Graphviz-14.0.5-win32\
   │   ├── bin\
   │   │   ├── dot.exe
   │   │   └── ...
   ```

> **Примітка:** Graphviz використовується **лише** проектом `dfa_generator__2025`. Якщо вам не потрібні діаграми FSM, цей крок можна пропустити.

## 📦 Опис проєктів

| Проєкт | Призначення |
| --- | --- |
| **`dfa_generator__2025`** | Генерує таблиці переходів DFA для лексичного аналізатора з регулярних виразів |
| **`dpda1_for_ll2_generator__2025`** | Створює документацію граматики LL(2) та автомата синтаксичного аналізатора |
| **`verify_syntax_by_EBNF_nonpacked__2025`** | Перевіряє коректність EBNF граматики через Boost.Spirit (детальний) |
| **`cw_sp2__2025_2026`** | Основний компілятор — лексичний, синтаксичний, семантичний аналіз та генерація коду |

## 🚀 Швидкий старт

### Крок 1: Відкриття проекту

1. **Встановіть залежності** (Boost обов'язково, Graphviz — опціонально)
2. **Відкрийте** `sp2025_var27.sln` у Visual Studio
3. **Виберіть конфігурацію:**
   - Solution Configuration: `Debug` (або `Release`)
   - Solution Platform: `x86` або `x64`
4. **Налаштуйте режим запуску:**
   - ПКМ на `Solution 'sp2025_var27'` → **Properties**
   - **Startup Project** → оберіть **Current selection**

---

### Крок 2: Генератор лексичного аналізатора

**Проєкт:** `dfa_generator__2025`

1. **Зберіть і запустіть**

**Результат:** У папці `built_src/` з'являться файли:
```
file1.hpp  file2.hpp  file3.hpp  file4.hpp
dfa.hpp    matcher_by_dfa.hpp
```

---

### Крок 3: Генератор граматики

**Проєкт:** `dpda1_for_ll2_generator__2025`

1. **Зберіть і запустіть**

**Результат:** У папці `built_doc/` з'являться файли:
```
Grammar_ANSI.txt    Grammar_UNICODE.txt
NPDA_ANSI.txt       NPDA_UNICODE.txt
```

---

### Крок 4 (опціонально): Перевірка граматики

**Проєкт:** `verify_syntax_by_EBNF_nonpacked__2025` (з Boost.Spirit) або `verify_syntax_by_EBNF__2025` (компактний)

Зберіть і запустіть для валідації EBNF граматики.

---

### Крок 5: Основний компілятор

**Проєкт:** `cw_sp2__2025_2026`

Зберіть і запустіть

**Результат:** Консоль виведе результат аналізу та згенерований код.
